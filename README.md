# Mi Portafolio Personal

Portafolio web personal de **Camilo**, aprendiz del SENA en el programa de Analisis y Desarrollo de Software.

## Estructura

```
├── index.html      # Pagina principal
├── css/
│   └── styles.css  # Estilos del portafolio
├── js/
│   └── script.js   # Interacciones y animaciones
└── img/
    └── foto.jpeg   # Foto de perfil
```

## Secciones

- **Sobre Mi** - Presentacion personal con foto y descripcion.
- **Educacion y Formacion** - Formacion tecnica en SENA y cursos especializados.
- **Habilidades Tecnicas** - Tarjetas interactivas con nivel de dominio en HTML, CSS, JavaScript y C++.
- **Proyectos** - Proyectos destacados desarrollados durante la formacion.
- **Contacto** - Medios de comunicacion: telefono, correo, GitHub y WhatsApp.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GSAP (animaciones)

## Ejecutar

Abre el archivo `index.html` en tu navegador preferido.
